# AI股票分析系统需求文档（PRD V1.0）

## 一、项目背景

### 1.1 项目名称

**AI Quant Platform（AI 股票分析平台）**

### 1.2 项目目标

构建一个面向 A 股市场的 AI
股票分析与量化研究平台，实现数据采集、可视化分析、AI
投研、量化策略、策略回测及 AI 问答等能力。

最终目标：

> 同花顺 + TradingView + 聚宽 + RiceQuant + ChatGPT 的融合平台。

# 六、AI分析中心

## 股票分析 Agent

输出： - 基本面分析 - 技术面分析 - 资金面分析 - 消息面分析 - 风险分析 -
AI 综合评分

## 板块分析 Agent

输出： - 板块热度 - 龙头股 - 补涨股 - 持续性 - 趋势分析

## 大盘分析 Agent

每日分析： - 指数趋势 - 市场情绪 - 成交量 - 赚钱效应 - 情绪周期 -
仓位建议

## 每日复盘 Agent

自动生成： - 今日热点 - 龙头股 - 炸板原因 - 资金流向 - 明日预判

## 股票推荐 Agent

综合分析： - 技术指标 - 资金流 - 新闻 - 板块热度 - 市场情绪 - 指数环境

输出： - 推荐股票 - 推荐理由 - 风险提示 - 止盈止损建议 - 仓位建议

# 八、回测中心

支持配置： - 策略 - 时间范围 - 初始资金 - 手续费 - 滑点

流程：

    策略
     ↓
    历史数据
     ↓
    信号计算
     ↓
    模拟交易
     ↓
    收益统计
     ↓
    生成报告

输出： - 收益率 - 最大回撤 - 胜率 - 夏普比率 - 卡玛比率 - 信息比率 -
盈亏比 - 收益曲线 - 回撤曲线 - 持仓变化

------------------------------------------------------------------------

# 九、AI助手

支持自然语言问答：

例如： - 今天为什么机器人板块上涨？ - 为什么推荐某只股票？ -
今天市场情绪如何？ - 龙头股是谁？ - 哪些股票符合低吸策略？

底层采用：

-   LLM
-   RAG
-   股票数据库
-   MCP Agent

# 十、推荐技术架构

    stock-platform

├── data-service（数据采集） ├── scheduler-service（定时同步） ├──
analysis-service（指标计算） ├── strategy-service（策略引擎） ├──
backtest-service（回测引擎） ├── ai-service（AI Agent） ├──
rag-service（知识库） ├── api-gateway（FastAPI） ├── web（Vue3） └──
admin（后台管理） ├── stock-data-service ├── stock-sync-service ├──
stock-analysis-service ├── stock-strategy-service ├──
stock-backtest-service ├── stock-ai-service ├── stock-search-service ├──
stock-api ├── stock-web └── stock-admin

  层         技术
  ---------- -----------------------------
  后端       Spring Boot 3 + Java 21
  ORM        MyBatis-Plus
  数据库     PostgreSQL + ClickHouse
  缓存       Redis
  MQ         Kafka / RocketMQ
  定时任务   XXL-Job
  搜索       Elasticsearch
  向量库     Milvus / pgvector
  AI         LangGraph / Spring AI
  前端       Vue3 + TypeScript + ECharts
  部署       Docker + Kubernetes
