## 一、项目背景（V1.5 增量）

### 1.1 版本定位

V1（MVP）已跑通「日K → K线 → AI 分析 → 策略回测 → 自然语言问答」主线闭环。
**V1.5 定位为「增量完善」**：在不动摇 V1 架构的前提下，补齐数据维度与展示能力，
让分析场景从"日K + 三指标"扩展到"多周期 + 多维度 + 情绪面 + 板块面"，
为 V2 的因子库与多 Agent 体系打好数据底座。

> V1.5 **不引入** Redis / Celery / ClickHouse / ES / 微服务拆分（这些是 V2 架构升级范畴）。
> V1.5 仍沿用 V1 的模块化单体 + cachetools 进程内缓存 + APScheduler 调度。

### 1.2 版本目标（V1.5）

1. **数据更全**：分钟K、龙虎榜、北向资金、分单资金、板块、情绪数据可采集可查询；
2. **展示更丰富**：K 线支持多周期与 4 种新指标，新增板块中心页与情绪指标区；
3. **运营可管**：admin 后台可管理数据源、采集任务、用户；
4. **零回归**：V1 全部功能与性能指标不退化。

### 1.3 成功标准

- 分钟K（至少 5 分钟周期）能采集并在 K 线页切换查看；
- 龙虎榜、北向资金、分单资金在个股详情有图表化展示；
- 板块中心页能展示板块热度排行、龙头股、主力资金流向；
- 行情总览新增涨停/跌停/炸板率/封板率/连板高度等情绪指标；
- 技术指标补齐 EMA/RSI/BOLL/筹码峰，可在 K 线副图/主图叠加；
- admin 后台可查看与触发采集任务、管理用户。

### 1.4 AI 输出声明（沿用 V1.2）

本系统所有 AI 输出仅作为研究参考信号，不构成投资建议，不保证准确性。
V1.5 新增的情绪/板块/资金数据同样仅作研究展示用途。

## 三、V1.5 功能范围

> 对应需求池 BP-V1.5-001 ~ BP-V1.5-011，共 11 条。
> 每条标注优先级（P0 必须 / P1 应做 / P2 可做）与所属模块。

### 3.1 数据中心（V1.5 增量）

#### BP-V1.5-001 · 分钟K数据采集（1/5/15/30/60/120 分钟）【P0】

- **目标**：补齐分钟级行情，支撑日内分析与多周期展示。
- **功能点**：
  - 采集 1/5/15/30/60/120 分钟 OHLCV；
  - 至少先覆盖**热门股池**（成交额 Top N）+ 用户触发个股按需拉取；
  - 支持增量同步与按需拉取两种模式。
- **采集策略**：
  - 盘后批量同步热门股池（控制数据源压力）；
  - 个股详情页首次请求分钟K时按需拉取并缓存。
- **验收**：
  - 热门股池 5 分钟K可查最近 N 个交易日；
  - 单股按需拉取分钟K < 3s（含数据源调用）；
  - 数据源限流失败时有降级（提示"分钟K获取失败，展示已有数据"）。

#### BP-V1.5-002 · 龙虎榜数据采集与展示【P1】

- **目标**：展示个股/市场龙虎榜（机构与游资席位动向）。
- **功能点**：
  - 采集当日龙虎榜：上榜原因（日涨幅偏离/换手率/振幅）、买卖席位明细（席位名称/净买入额/是否机构）；
  - 个股详情展示该股近 N 日上榜记录；
  - 行情/板块维度可聚合"今日龙虎榜"列表。
- **验收**：
  - 交易日 18:00 后龙虎榜可查；
  - 个股详情能展示席位买卖明细表；
  - 支持按"机构席位/游资席位"筛选。

#### BP-V1.5-003 · 北向资金数据采集与展示【P1】

- **目标**：展示北向资金（外资）整体与个股维度动向。
- **功能点**：
  - 沪股通/深股通每日净买入额、成交净额；
  - 个股维度：该股北向持股变化（可选，视数据源能力）；
  - 行情总览展示北向资金当日净流入卡片 + 近 N 日趋势。
- **验收**：
  - 行情总览有北向资金卡片（红绿表示净流入/流出）；
  - 个股详情展示该股北向持股变动（若数据源支持）；
  - 盘后数据可查。

#### BP-V1.5-004 · 超大/大/中/小单资金明细【P1】

- **目标**：细化 V1 的"主力资金净流入"，拆分为四档资金流向。
- **功能点**：
  - 采集个股每日超大单/大单/中单/小单净流入；
  - 个股详情展示资金流向图（四档堆叠柱状或流向条）；
  - 支持近 N 日趋势。
- **与 V1 关系**：V1 的 `sa_money_flow` 只有主力净流入汇总，V1.5 新增 `sa_money_flow_detail` 存四档明细，二者并存。
- **验收**：
  - 个股详情有四档资金流向图；
  - 数据与 `sa_money_flow.main_net_inflow` 口径一致（超+大单 ≈ 主力）。

#### BP-V1.5-010 · admin 后台管理【P1】

- **目标**：提供运营后台，管理数据源、采集任务、用户。
- **功能点**：
  - **数据源管理**：查看各数据源状态（AkShare/Tushare）、限流配置、连通性检测；
  - **采集任务管理**：查看任务列表、最近执行状态（成功/失败/耗时）、手动触发重跑、查看日志；
  - **用户管理**：用户列表、禁用/启用、角色标记（V1.5 仅普通用户/admin 两级）。
- **访问控制**：独立 admin 路由前缀，仅 admin 角色可访问。
- **验收**：
  - admin 可查看所有采集任务执行历史；
  - 可手动触发任意采集任务重跑并看到结果；
  - 可禁用/启用用户。

### 3.2 数据展示（V1.5 增量）

#### BP-V1.5-005 · 板块中心【P0】

- **目标**：新增板块中心页，展示板块热度、龙头股、梯队、成交额、涨停家数、主力资金流向。
- **功能点**：
  - **板块热度排行**：按涨跌幅/成交额/资金净流入排序的行业/概念板块列表；
  - **板块详情**：点击板块进入，展示成分股列表（按涨幅排序）、龙头股、梯队（涨停/领涨）；
  - **板块资金流向**：板块主力资金净流入排行（红/绿）；
  - **板块涨停家数**：各板块当日涨停家数分布。
- **验收**：
  - 板块中心页可按行业/概念切换；
  - 板块详情能展示成分股与龙头；
  - 板块资金流向排行可排序。

#### BP-V1.5-006 · 情绪指标【P1】

- **目标**：在行情总览展示市场情绪指标。
- **功能点**：
  - 涨停数 / 跌停数；
  - 炸板率（曾涨停但未封住的比例）；
  - 封板率（封住涨停占触及涨停比例）；
  - 连板高度（最高连板数，如几板）；
  - 涨停梯队（按连板数分组的家数分布，如 1 板 X 家 / 2 板 Y 家 …）。
- **计算口径**：基于 `daily_prices` 当日涨跌停规则（涨停 = 涨幅达 ±10%/20% 限制，按板块规则）+ 当日最高价触及涨停价判定炸板。
- **验收**：
  - 行情总览新增情绪指标卡片区；
  - 涨停梯队有可视化（阶梯条形图）；
  - 非交易日展示最近交易日数据 + 提示。

#### BP-V1.5-007 · 技术指标扩展（EMA / RSI / BOLL / 筹码峰）【P0】

- **目标**：在 V1 的 MA/MACD/KDJ 基础上补齐 4 种指标。
- **功能点**：
  - **EMA**（指数移动平均）：主图叠加，EMA12/EMA26 等周期可切换显隐；
  - **RSI**（相对强弱指标）：副图，RSI6/RSI12/RSI24，标注超买(>70)/超卖(<30)区间；
  - **BOLL**（布林带）：主图叠加，上轨/中轨/下轨 + 价格突破轨道标注；
  - **筹码峰**：副图/侧栏，基于 `chip_distribution` 展示筹码分布柱状图（获利盘比例、平均成本、90% 集中度）。
- **与 V1 关系**：V1 指标接口 `/stock/{code}/indicators?type=` 的 `type` 枚举从 `ma|macd|kdj` 扩展为 `ma|ema|macd|kdj|rsi|boll`；筹码峰走独立接口（读 `chip_distribution`）。
- **验收**：
  - K 线页指标 Tab 新增 EMA/RSI/BOLL，可切换；
  - 主图叠加（EMA/BOLL）与副图（RSI）正确渲染；
  - 筹码峰图展示获利盘比例与集中度；
  - 计算性能：单指标一年数据 < 500ms。

#### BP-V1.5-008 · 资金流向图、财务指标图表化【P1】

- **目标**：将 V1 的数字型财务/资金展示升级为图表。
- **功能点**：
  - **资金流向图**：主力/四档资金近 N 日净流入折线或堆叠柱状（与 BP-V1.5-004 联动）；
  - **财务指标图表化**：PE/PB/ROE/EPS/营收增长/净利润增长 近 N 期趋势图（折线）。
- **验收**：
  - 个股详情资金区有趋势图；
  - 财务卡片支持展开查看历史趋势。

#### BP-V1.5-009 · 多周期切换（分钟/周/月）【P2】

- **目标**：K 线支持分钟/周/月周期切换。
- **功能点**：
  - 周期选项：1分/5分/15分/30分/60分（来自 BP-V1.5-001）/ 日（V1）/ 周 / 月；
  - 周K/月K由 `daily_prices` 聚合计算（无需新表）；
  - 各周期下指标同步重算。
- **与 V1 关系**：V1 K 线页周期切换项"分钟/周/月"为置灰"V1.5 上线"，本需求将其激活。
- **验收**：
  - 周期切换可用且数据正确（周K = 周内日K合并 OHLC、成交量求和）；
  - 切换周期后指标与十字光标同步刷新；
  - 分钟周期数据缺失时降级提示。

#### BP-V1.5-011 · 行情总览增强：实时情绪面【P1】

- **目标**：行情总览补齐涨停/跌停数量、涨跌家数等实时情绪面（与 BP-V1.5-006 互补，006 偏深度情绪指标，011 偏总览即时数字）。
- **功能点**：
  - V1 行情总览已有涨跌家数、成交额，本需求补充涨停家数、跌停家数、曾涨停（炸板）家数；
  - 强化涨跌家数展示（上涨/下跌/平盘 + 涨停/跌停 分组对比条）。
- **验收**：
  - 行情总览顶部数字区包含涨停/跌停/炸板家数；
  - 与 BP-V1.5-006 的情绪卡片区数据一致（同源计算）。

#### BP-V1.5-012 · 股票列表（轻量浏览与筛选）【P1】

- **背景**：V1 查看个股仅有「搜索框」和「列表点击跳转」两个入口，缺少一个
  浏览/筛选全市场股票的独立页面。本需求补一个**轻量版股票列表页**，
  让用户能按行业、涨跌幅、成交额、市值等条件分页浏览并进入个股详情。
  > 与 V2「选股器（多条件组合筛选 / 漏斗筛选）」区分：本需求只做单维度
  > 排序 + 行业筛选 + 分页，不做复杂多条件组合（现有库 `screen_result` 已是
  > 选股器方向，留待 V2）。
- **目标**：提供全市场股票的分页浏览页，支持行业筛选与多字段排序，作为个股详情的主要发现入口。
- **数据源**：复用现有 `stock_pool` 表（字段齐全：名称/交易所/行业/市值/PE/PB/涨跌幅/成交额），**只读，无需新建表**。
- **功能点**：
  - **分页列表**：默认每页 20/50 条可切换，展示代码、名称、行业、现价、涨跌幅（红/绿）、成交额、总市值、PE；
  - **行业筛选**：下拉选择行业（来自 `stock_pool.industry` 去重），可清空；
  - **排序**：表头点击按 涨跌幅 / 成交额 / 总市值 / PE 升降序切换；
  - **快捷筛选**（可选轻量标签）：全部 / 涨停 / 跌停 / 涨幅前 N，便于快速定位；
  - 行点击 → 进入「股票详情」页。
- **与 V1 关系**：V1 的 `search_stocks(q, limit)` 仅支持带关键词模糊搜索、不分页；
  `get_hot_stocks(sort, limit)` 固定按成交额/涨幅、无筛选无分页。
  本需求新增**支持分页 + 行业筛选 + 多字段排序**的列表接口与页面。
- **验收**：
  - 股票列表页可分页浏览全市场股票；
  - 行业筛选、表头排序、快捷标签均生效；
  - 行点击跳转个股详情；
  - 接口性能：分页查询 < 800ms (P95)，走 `stock_pool` 索引；
  - 行业为 NULL 的个股归入「未分类」或可被「全部」覆盖。

### 4.2 数据合规与风险（沿用 V1.2）

- 数据源仅用 AkShare / Tushare 等公开授权渠道，不爬付费/版权数据；
- **V1.5 不对接任何交易接口**（模拟交易下沉 V2/V3）；
- 所有页面保留底部风险提示；
- 数据源限流：分钟K等高频采集严格控并发，失败重试 + 降级；
- 龙虎榜席位数据仅展示公开席位名称，不涉及个人隐私。

### 4.3 可用性

- V1.5 目标可用性维持 95%；
- 新增采集任务失败需告警日志（写入 `sa_admin_task_log`），admin 可手动重跑；
- 分钟K等依赖外部数据源的功能，数据缺失时降级而非阻断页面。

### 4.4 安全

- admin 后台独立鉴权，仅 admin 角色；
- 采集任务手动触发需登录 + admin 权限校验；
- 敏感配置（数据源 Token、LLM Key）继续走环境变量，不入库；
- 接口限流：分钟K按需拉取按用户限频，防止滥用数据源配额。

## 八、版本边界与不做的事（V1.5 Out-of-Scope）

为避免范围蔓延，明确 V1.5 **不做**（下沉 V2/V3）：

- ❌ 完整量化因子库（趋势/动量/波动率/成交量/基本面/情绪 6 大类）→ V2
- ❌ 多策略（EMA/趋势/龙头/打板/低吸/突破）→ V2
- ❌ 高级回测指标（卡玛/信息比率/盈亏比/回撤曲线/持仓变化）→ V2
- ❌ RAG 知识库 / 向量库 → V2
- ❌ ES 全文搜索 → V2
- ❌ 多 Agent（板块/大盘/复盘/推荐 Agent）→ V2/V3
- ❌ Redis / Celery / ClickHouse / 微服务拆分 → V2 架构升级
- ❌ 模拟/实盘交易 → V2/V3
- ❌ 新闻情绪分析（实时资讯爬取）→ V2
