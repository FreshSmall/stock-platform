# AI股票分析系统需求文档（PRD V1.2）

> 版本说明：V1.2 相对 V1.1 的主要变更
> 1. 修正技术栈矛盾（统一为 Python/FastAPI），前端定为 React + TypeScript；
> 2. 收敛 V1 范围为精简 MVP，将原 V1 中过重或非核心的需求下沉到 V1.5/V2/V3；
> 3. 新增「非功能性需求」「合规与风险声明」「AI 输出声明」章节；
> 4. 简化技术架构（模块化单体，后续再拆微服务）；
> 5. 新增「前端交互设计」章节（页面级布局 + 交互流程）；
> 6. 数据层复用现有 `stock_analysis` 库（详见第二章 §2.2 数据层设计）。

## 一、项目背景

### 1.1 项目名称

**AI Quant Platform（AI 股票分析平台）**

### 1.2 项目定位

面向 A 股市场的 **AI 辅助投研工具**（AI-assisted Research Tool）。
聚焦个人投资者/研究者，提供「数据 → 分析 → 策略 → 回测」一条主线的研发闭环。

> 注：V1 不追求"同花顺 + TradingView + 聚宽 + RiceQuant + ChatGPT 五合一"
> 这种过宽定位，而是先把核心闭环跑通，再按里程碑横向扩展。

### 1.3 项目目标（V1 / MVP）

构建一个可运行的最小闭环：

> **数据采集（日K + 基础财务）→ K线展示 → AI 股票分析 → 策略 + 回测 → 自然语言问答**

成功标准：
- 能采集并更新 A 股日K行情与基础财务数据；
- 用户能在 Web 上查看 K 线 + 主要技术指标；
- AI 能对单只股票输出结构化分析（基本面/技术面/资金面/消息面 + 综合评分）；
- 用户能基于内置策略跑一次历史回测，得到收益率/回撤/夏普等核心指标；
- 用户能用自然语言向 AI 提问（基于结构化数据 + LLM）。

### 1.4 AI 输出声明（重要）

本系统的所有 AI 输出（分析、评分、推荐、问答等）**仅作为研究参考信号**，
**不构成任何投资建议**，也**不保证准确性**。AI 输出不可作为唯一决策依据，
用户需自行判断并承担风险。系统会在所有 AI 输出位置显著标注此声明。

## 二、总体架构（V1 模块化单体）

V1 采用 **模块化单体（Modular Monolith）**：单一 FastAPI 应用内按业务领域分模块，
降低部署与运维复杂度；待规模增长后再按模块拆分为独立服务。

``` text
                        ┌──────────────────────────┐
                        │   Web (React + TS + Vite)│
                        └────────────┬─────────────┘
                                     │ HTTPS / REST (+ SSE for AI流式)
                        ┌────────────▼─────────────┐
                        │   FastAPI App (单体)      │
                        │  ┌────────────────────┐   │
                        │  │ data  (采集/同步)   │   │
                        │  │ market(行情/指标)   │   │
                        │  │ ai    (Agent/问答)  │   │
                        │  │ strategy(策略/回测) │   │
                        │  │ user  (认证/偏好)   │   │
                        │  └────────────────────┘   │
                        └───┬──────────────┬──────────┘
                            │              │
                 ┌──────────▼──────┐  ┌────▼───────────┐
                 │ MySQL           │  │ LLM API         │
                 │ stock_analysis  │  │ (DeepSeek 等)   │
                 │ (行情+产物同库)  │  └─────────────────┘
                 └──────┬──────────┘
                        │
                 ┌──────▼─────────────────┐
                 │  数据源 (AkShare 等)    │
                 └────────────────────────┘
```

> 注：V1 不引入 Redis，使用进程内缓存（cachetools）过渡，
> 用于行情查询缓存与 AI 分析结果冷却。V2 引入 Redis（缓存 + 限流 + Celery broker）。

### 2.1 技术栈

| 层         | 技术                                            |
| ---------- | ----------------------------------------------- |
| 后端       | **Python 3.11 + FastAPI + Uvicorn**             |
| ORM        | SQLAlchemy 2.0 + Alembic                        |
| 数据库     | **MySQL（复用现有 `stock_analysis` 库）**       |
| 缓存       | **V1：cachetools 进程内缓存**；V2：Redis        |
| 任务调度   | APScheduler（V2 升级至 Celery）                 |
| 量化计算   | pandas + numpy + TA-Lib + backtrader            |
| AI         | LangChain / LangGraph（DeepSeek / 通义 / GPT）   |
| 前端       | **React 18 + TypeScript + Vite**                |
| 图表       | ECharts（K线/指标）+ Lightweight Charts（备选）  |
| UI 组件    | Ant Design 5                                    |
| 状态管理   | Zustand（轻量）/ React Query（服务端状态）      |
| 部署       | Docker Compose（V1）；K8s 留待 V2                |

> 说明：相比 V1.1，移除了 Spring Boot、MyBatis-Plus、XXL-Job、ES、Milvus、
> Kafka、K8s、Redis 等过重组件，统一为 Python 生态，降低复杂度。

#### 2.2.4 数据采集任务（V1）

- **日K增量同步**：每日收盘后增量拉取写入 `daily_prices`（沿用既有任务，本系统可触发或监听）；

- **主力资金**：写入 `sa_money_flow`（现有库无）；
- **行业字段补全**：回填 `stock_pool` 的 `industry`（当前部分为 NULL）。

> 数据校验沿用既有 `job_runs` 机制，或在新表中记录同步状态。

## 三、V1 功能范围（MVP）

### 3.1 数据中心（V1）

**数据采集（V1 仅含）**
- 股票基础信息：代码、名称、所属行业、所属概念、上市时间、总市值、流通市值
- 日K行情：开/收/高/低、成交量、成交额、涨跌幅、振幅、换手率
- 基础财务：PE、PB、ROE、EPS、营收增长率、净利润增长率
- 基础资金：主力资金净流入

> 下沉到 V1.5/V2：分钟K、龙虎榜、北向资金、超大/大/中/小单明细、
> 现金流/毛利率/资产负债率等深度财务、新闻数据。

**数据同步**
- 日K：交易日收盘后定时全量同步（APScheduler）
- 财务：季度更新
- 数据校验：缺失值、异常涨跌幅（>±20% 校验）、重复键检测

### 3.2 数据展示（V1）

**股票详情**
- K 线（日K）
- 技术指标：MA、MACD、KDJ（V1 三种）
- 成交量

> 下沉到 V1.5/V2：EMA、RSI、BOLL、筹码峰、资金流向图、财务指标图表、
> 多周期（分钟/周/月）。

**行情总览（V1 简化）**
- 大盘指数（上证/深证/创业板）实时点位 + 涨跌幅
- 涨跌家数
- 市场成交额

> 下沉到 V1.5：涨停/跌停数量、炸板率、封板率、连板高度、涨停梯队
> 等情绪类指标（属于打板/情绪交易专用）。

### 3.3 AI 分析中心（V1）

**股票分析 Agent（V1 唯一一个 Agent）**

输入：股票代码
输出（结构化）：
- 基本面分析（基于财务数据）
- 技术面分析（基于 K 线 + MA/MACD/KDJ）
- 资金面分析（基于主力资金）
- 消息面分析（V1 仅基于公开财务/公告摘要，无实时新闻爬取）
- 风险提示
- AI 综合评分（0-100，附评分维度拆解）

> 下沉到 V2：板块分析 Agent、大盘分析 Agent、每日复盘 Agent、股票推荐 Agent
> （多 Agent 体系）。

### 3.4 策略中心（V1）

**内置策略（V1 仅 2 种）**
- MA 策略（金叉/死叉）
- MACD 策略（金叉/死叉 + 背离）

**策略回测（V1）**
配置：股票池（单只或多只）、时间范围、初始资金、手续费、滑点
输出指标：
- 收益率
- 最大回撤
- 夏普比率
- 胜率
- 收益曲线

> 下沉到 V2：其余 6 种策略（EMA/趋势/龙头/打板/低吸/突破）、
> 完整因子库（趋势/动量/波动率/成交量/基本面/情绪 6 大类）、
> 卡玛比率/信息比率/盈亏比/回撤曲线/持仓变化等高级回测指标。

### 3.5 AI 助手（V1）

自然语言问答（基于 LLM + 结构化数据）：
- "分析一下 600519"
- "MACD 金叉的股票有哪些"
- "帮我回测 MA 策略在白酒板块近一年的表现"

V1 实现方式：LLM + Function Calling（调用结构化数据查询/分析接口），
**不引入 RAG / 向量库**（下沉到 V2）。

## 四、非功能性需求（新增）

### 4.1 性能
- K 线接口：单只股票一年日K查询 < 500ms（P95）
- AI 分析：单只股票分析响应 < 15s（含 LLM 调用）
- 回测：单只股票 5 年日K回测 < 10s
- 前端首屏加载 < 3s

### 4.2 数据合规与风险
- 数据源仅使用 AkShare / Tushare 等具备公开授权的渠道，
  **不爬取付费/版权数据**；
- 系统不存储用户实盘账户信息，**V1 不对接任何交易接口**；
- 所有页面底部固定展示风险提示；
- 数据源限流：单数据源并发 ≤ 其官方限制，失败重试 + 降级。

### 4.3 可用性
- V1 目标可用性 95%（个人/研究工具定位，非生产交易系统）；
- 数据同步任务失败需有告警日志，支持手动重跑。

### 4.4 安全
- 用户认证：JWT；
- 接口限流：登录用户级 rate limit；
- 敏感配置（LLM API Key、数据源 Token）通过环境变量注入，不入库。

### 5.1 全局导航与布局

**整体布局：左侧导航 + 顶部栏 + 主内容区**

```
┌──────────────────────────────────────────────────────────┐

├──────┬───────────────────────────────────────────────────┤
```

### 5.3 各页面交互设计

#### 页面1：行情总览 `/market`

**布局**
- 顶部：三大指数卡片（上证/深证/创业板），每张卡片显示点位、涨跌幅、涨跌颜色（红涨绿跌，符合A股习惯）。
- 中部：市场成交额、涨跌家数（上涨/下跌/平盘，红色/绿色条形对比）。
- 下部：热门个股表（按成交额/涨幅排序，列：代码、名称、现价、涨跌幅、成交额）。

**交互**
- 指数卡片点击 → 跳转对应指数成分股列表（V1 可简化为跳转上证指数 ETF 详情）。
- 热门个股表行点击 → 进入「股票详情」页。
- 表头点击列名 → 排序。

**状态**
- 加载中：骨架屏（Skeleton）。
- 数据为空（非交易日/盘前）：显示提示"当前为非交易时段，展示最近交易日数据"。

#### 页面2：股票详情 `/stock/:code`

**布局（自上而下）**
1. 个股头部：名称、代码、现价、涨跌幅、涨跌额（大字号，红/绿）。
2. K 线主图区（ECharts）：
   - 主图：日K（蜡烛图）+ MA（MA5/MA10/MA20 可切换显隐）。
   - 副图1：成交量（柱状）。
   - 副图2：MACD 或 KDJ（技术指标 Tab 切换：MACD / KDJ）。
3. 右侧/下部：基础财务卡片（PE/PB/ROE/EPS/营收增长/净利润增长）。
4. 操作按钮：「AI 分析」→ 跳转 `/analysis/:code`。

**交互**
- K 线缩放：鼠标滚轮缩放、拖拽平移、双击重置。
- 周期切换：日K（V1 仅日K，其余周期置灰提示"V1.5 上线"）。
- 指标 Tab：在 MACD / KDJ 间切换副图指标。
- 十字光标：鼠标悬停显示当日 OHLC、成交量、指标数值浮窗。
- MA 显隐：图例点击切换。
- 「AI 分析」按钮：携带 code 跳转分析页。

**状态**
- 加载中：K 线区显示 Loading 占位。
- 个股不存在：404 提示 + 返回行情总览按钮。
- 数据源异常：K 线区显示"数据获取失败，[重试]"。

#### 页面3：AI 股票分析 `/analysis/:code`

**布局**
- 顶部：复用个股头部（名称/价格/涨跌）。
- 综合评分卡：大号 0-100 分 + 等级（如 强烈关注/中性/谨慎）+ 维度雷达图（基本面/技术面/资金面/消息面/风险 各 0-100）。
- 分析正文（Tab 或卡片纵向排列）：
  - 基本面分析
  - 技术面分析
  - 资金面分析
  - 消息面分析
  - 风险提示
- 每段分析末尾固定：「⚠ 以上为 AI 生成的参考信号，不构成投资建议」。

**交互**
- 「重新分析」按钮：触发新一轮 AI 分析（限流：同一只股票 N 分钟内仅允许 1 次）。
- 流式输出：AI 分析采用 SSE 流式返回，正文逐段打字机式呈现，避免长时间空白等待。
- 评分维度点击：雷达图维度点击可滚动定位到对应分析段落。
- 复制/分享：分析结果支持一键复制为文本。

**状态**
- 分析中：综合评分区显示 Loading + 进度提示（"正在分析基本面…/技术面…"）。
- 分析失败：错误提示 + 重试按钮。
- 限流命中：Toast 提示"该股票分析冷却中，请 X 分钟后再试"。

#### 页面4：策略列表 `/strategy`

**布局**
- 策略卡片网格：每张卡片含 策略名、简述、适用场景、参数说明、"回测此策略"按钮。
- V1 展示 2 张卡片：MA 策略、MACD 策略；其余策略卡片置灰标注"V2 上线"。

**交互**
- 卡片点击"回测此策略" → 跳转 `/backtest?strategy=ma`。
- 卡片悬停显示参数详情 Tooltip。

#### 页面5：回测配置与结果 `/backtest`

**布局（左右或上下分栏）**
- 左/上：回测配置表单
  - 选择策略（MA / MACD）
  - 策略参数（如 MA 的短/长周期）
  - 股票池（V1 支持单只选股 + 少量自选组合）
  - 时间范围（起止日期）
  - 初始资金、手续费率、滑点
  - 「开始回测」按钮
- 右/下：回测结果
  - 核心指标卡：收益率、最大回撤、夏普比率、胜率
  - 收益曲线图（策略 vs 基准）
  - 交易明细表（买卖点、盈亏）

**交互**
- 表单校验：日期合法性、资金 > 0、必选项校验，错误 inline 提示。
- 回测执行：点击后按钮置 Loading，结果区显示进度；完成后渲染指标与曲线。
- 收益曲线：K 线/折线叠加买卖点标记（BS 标识）。
- 交易明细表：支持分页、按盈亏排序、导出 CSV。
- 「保存回测」：将本次配置与结果存入用户历史（V1 可选）。

**状态**
- 回测中：进度条 + 可取消按钮。
- 回测失败：错误提示（如"该区间数据缺失"）。
- 结果为空（无交易信号）：提示"当前参数下未产生交易信号，请调整参数"。

#### 页面6：AI 助手对话 `/assistant`

**布局**
- 类 ChatGPT 三栏式（V1 简化为单栏对话）：
  - 顶部：标题 + "新对话"按钮。
  - 中部：消息流（用户消息右侧、AI 消息左侧，AI 消息支持表格/列表渲染）。
  - 底部：输入框 + 发送按钮 + 示例问题 Chips（如"分析 600519""MACD 金叉股票"）。
- 每条 AI 回复底部：「⚠ 仅供参考，不构成投资建议」+ 复制/重新生成。

**交互**
- 流式回答：SSE 打字机输出。
- Function Calling 可视化：当 AI 调用工具（如查询行情/回测）时，
  在消息内显示"正在查询 600519 行情…"的步骤条，工具结果可折叠展开。
- 上下文关联：对话保留最近 N 轮上下文。
- 示例 Chips 点击：填入输入框并直接发送。

**状态**
- AI 思考中：输入框上方显示"正在思考…"动画 + 可停止按钮。
- 发送失败：消息旁显示重试图标。
- 内容安全：检测到敏感词（如具体买卖指令）时，AI 回复统一风险声明。

### 5.4 全局交互规范

- **红涨绿跌**：全站涨跌颜色遵循 A 股习惯（红=涨，绿=跌）。
- **加载态**：统一用 Skeleton（结构已知）或 Spinner（操作触发）。
- **空态**：每个列表/图表提供插画 + 引导文案。
- **错误态**：网络错误统一 Toast；致命错误（404/500）用结果页。
- **数字格式**：金额千分位、百分比保留 2 位、价格保留 2 位小数。
- **响应式**：V1 优先 PC 端（≥1280px），移动端仅保证可用（不阻断）。
- **可访问性**：颜色之外附加图标/文字区分涨跌（色盲友好）。

## 七、项目定位（V1 收敛）

本系统 V1 定位为 **AI 辅助的 A 股投研工具（AI-assisted Research Tool）**，
而非全功能量化交易平台。V1 聚焦：

1. 基础数据平台（日K + 财务 + 资金）
2. 行情与指标展示
3. 单一 AI 股票分析 Agent
4. 轻量策略与回测闭环
5. 自然语言 AI 助手

后续按 V1.5 → V2 → V3 逐步演进为完整的 AI 量化投研平台。
