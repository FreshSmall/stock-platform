# AI股票分析系统需求文档（PRD V2.0）

> 版本说明：V2 相对 V1.5 的主要变更
> 1. **量化因子体系**：从 V1 的 2 种策略 + 6 种指标，升级为完整因子库（趋势/动量/波动率/成交量/基本面/情绪 6 大类），并支持多因子组合；
> 2. **多策略**：策略中心从 2 种扩展到 8 种（新增 EMA/趋势/龙头/打板/低吸/突破），并支持自定义参数；
> 3. **高级回测**：回测指标从 5 个扩展到 10+（卡玛比率/信息比率/盈亏比/回撤曲线/持仓变化），并支持多股票组合回测与基准对比；
> 4. **RAG 知识库**：AI 助手从"LLM + 结构化数据"升级为"LLM + RAG"，支持基于研报/公告/财报的问答；
> 5. **多 Agent**：从单一股票分析 Agent 扩展为板块/大盘/复盘/推荐 4 个 Agent；
> 6. **新闻情绪**：引入实时资讯采集与情绪打分。
>
> **架构策略（重要）**：V2 业务优先，**架构升级（Redis/Celery/ClickHouse/ES/微服务/K8s）缓做**，下沉至 V2.5。
> V2 继续沿用 V1 的模块化单体 + cachetools + APScheduler + MySQL，仅在必要处引入轻量组件（如 pgvector 向量库复用 MySQL）。
>

## 一、项目背景（V2 增量）

### 1.1 版本定位

V1（MVP）跑通了「日K → K线 → AI 分析 → 策略回测 → 问答」主线；
V1.5 补齐了数据维度（分钟K/资金/板块/情绪/指数）与展示能力。
**V2 定位为「量化研究平台化」**：从"分析工具"升级为支持因子研究、多策略验证、组合回测、知识增强问答的量化研究平台。

> V2 不追求"全功能量化交易终端"，而是先把**研究闭环**做深：
> 因子有效性检验 → 多策略回测 → 组合管理 → AI 辅助投研。
> 实盘交易仍下沉 V3。

### 1.2 版本目标（V2）

1. **因子可研究**：6 大类因子可计算、可回测、可检验有效性（IC 分析）；
2. **策略可组合**：8 种策略 + 多因子模型，支持参数调优与组合回测；
3. **回测可深入**：10+ 高级指标 + 回撤曲线 + 持仓变化 + 基准对比；
4. **AI 可信赖**：RAG 知识库让 AI 问答基于真实研报/公告，而非纯 LLM 推测；
5. **多 Agent 协同**：板块/大盘/复盘/推荐 4 个 Agent 覆盖投研全场景。

### 1.3 成功标准

- 因子库覆盖 6 大类共 30+ 因子，每个因子可单独回测并输出 IC/胜率；
- 策略中心 8 种策略全部可用，支持自定义参数与组合回测；
- 回测产出 10+ 指标 + 回撤曲线 + 持仓变化 + 基准对比；
- RAG 知识库可导入研报/公告，AI 助手能基于知识库回答"某公司最新研报怎么说"；
- 4 个 Agent 能分别输出板块分析/大盘研判/每日复盘/个股推荐。

### 1.4 AI 输出声明（沿用）

所有 AI 输出（因子建议、策略信号、Agent 分析、推荐）仅作研究参考，不构成投资建议。

## 二、总体架构（V2 增量）

V2 **不改变 V1 的整体架构**（FastAPI 模块化单体 + React SPA + MySQL），
仅在 `strategy` 模块大幅扩展（因子库 + 多策略）、`ai` 模块新增 RAG 与多 Agent。
架构升级（Redis/Celery/ClickHouse/ES/微服务）**缓做**，下沉 V2.5。

                        ┌────────────▼─────────────┐
                        │   FastAPI App (单体)      │

                        │  │ market 行情/指标     │   │ ← 沿用 V1.5（6指标+多周期）
                        │  │ strategy 因子+策略 ★ │   │ ← V2 重点扩展：因子库+8策略+多因子
                        │  │ ai     Agent/RAG ★  │   │ ← V2 重点扩展：RAG+4 Agent

| 层 | 技术 | V2 说明 |

## 三、V2 功能范围

> 对应需求池 BP-V2-001 ~ BP-V2-014，共 14 条业务需求。
> 架构升级 5 条（BP-V2-A01~A05）下沉 V2.5，本 PRD 不展开。

### 3.1 策略中心（V2 重点）

#### BP-V2-001 · 完整量化因子库【P0】

- **目标**：建立可计算、可回测、可检验的因子库，作为量化研究的基石。
- **因子分类（6 大类，30+ 因子）**：

| 大类 | 因子 | 计算源 |
|---|---|---|
| **趋势** | MA、EMA、MACD、ADX、SuperTrend | `daily_prices` |
| **动量** | RSI、KDJ、ROC、CCI | `daily_prices` |
| **波动率** | ATR、BOLL、HV（历史波动率） | `daily_prices` |
| **成交量** | OBV、VOL（量比）、换手率、量价比 | `daily_prices` |
| **基本面** | PE、PB、ROE、EPS、营收增长、净利润增长 | `stock_pool` / `sa_financial_extra` |
| **情绪** | 涨停数、炸板率、北向资金、板块热度、连板高度 | `sa_market_sentiment` / `sa_north_flow` |

- **功能点**：
  - 每个因子定义为 `(code, name, category, formula, params)`，统一接口 `compute(code, stock, date) → value`；
  - 因子值落 `sa_factor_value`，支持按股票/日期/因子查询；
  - 因子可叠加到 K 线图（与 V1.5 指标叠加复用）；
  - 因子可单独回测（验证其预测能力）。
- **与 V1/V1.5 关系**：V1 的 MA/MACD/KDJ + V1.5 的 EMA/RSI/BOLL 已是趋势/动量/波动率类的子集，V2 将其纳入统一因子框架并补齐缺失项（ADX/SuperTrend/ROC/CCI/ATR/OBV 等）。
- **验收**：
  - 因子库 ≥ 30 个，覆盖 6 大类；
  - 单因子计算 < 500ms（一年数据）；
  - 因子值可查询、可叠加 K 线、可单独回测。

#### BP-V2-002 · 策略中心扩展（8 种策略）【P0】

- **目标**：策略从 2 种扩展到 8 种，覆盖主流交易模式。
- **新增策略（V1 已有 MA/MACD，V2 新增 6 种）**：

| 策略 | 信号逻辑 | 适用场景 |
|---|---|---|
| **EMA 策略** | EMA 金叉/死叉（EMA12/26） | 趋势跟踪 |
| **趋势策略** | ADX > 阈值 + MA 多头排列 | 强趋势确认 |
| **龙头策略** | 板块涨幅前 N + 放量 | 板块龙头捕捉 |
| **打板策略** | 触及涨停 + 封板率/连板 | 涨停板交易 |
| **低吸策略** | 回踩 MA20/支撑位 + 缩量 | 回调买入 |
| **突破策略** | 突破 BOLL 上轨/前高 + 放量 | 突破交易 |

- **功能点**：
  - 每种策略参数可配置（如 MA 周期、ADX 阈值、龙头 Top N）；
  - 策略可回测（接 V2 回测引擎）；
  - 策略卡片在 V1.5 置灰的项激活。
- **验收**：8 种策略全部可回测，参数可调。

#### BP-V2-004 · 多因子模型【P1】

- **目标**：支持多因子加权打分选股。
- **功能点**：
  - 用户选择 N 个因子 + 权重，系统计算每只股票的综合得分；
  - 支持因子权重预设（如"价值+动量"组合）；
  - 输出 Top N 选股列表（接 BP-V2-012 推荐 Agent）。
- **验收**：多因子打分可生成选股列表，权重可调。

#### BP-V2-005 · 组合管理【P1】

- **目标**：支持用户创建/管理股票组合，并做组合回测。
- **功能点**：
  - 创建组合（名称 + 股票池 + 权重）；
  - 组合净值计算（加权）；
  - 组合回测（整体收益/回撤/夏普，与基准对比）；
  - 组合调仓记录。
- **验收**：组合可创建、可回测、可对比基准。

### 3.2 回测中心（V2 增强）

#### BP-V2-003 · 回测高级指标【P0】

- **目标**：回测指标从 5 个扩展到 10+，并增加可视化。
- **新增指标**：

| 指标 | 说明 |
|---|---|
| 卡玛比率（Calmar） | 年化收益 / 最大回撤 |
| 信息比率（IR） | 超额收益 / 跟踪误差 |
| 盈亏比 | 平均盈利 / 平均亏损 |
| 回撤曲线 | 逐日回撤序列（图） |
| 持仓变化 | 逐日持仓/仓位（图） |
| 净值曲线（策略 vs 基准） | 叠加对比 |

- **与 V1 关系**：V1 有收益率/最大回撤/夏普/胜率/收益曲线，V2 补齐上述 + 基准对比。
- **验收**：回测产出 10+ 指标 + 回撤曲线 + 持仓图 + 净值对比。

#### BP-V2-013 · 因子研究平台【P2】

- **目标**：因子有效性检验与 IC 分析的可视化平台。
- **功能点**：
  - 单因子 IC 分析（信息系数：因子值 vs 未来收益相关性）；
  - 因子累积 IC 曲线；
  - 因子分层收益（按因子值分 5 档，看各档收益）；
  - 因子衰减（IC 随持有天数变化）。
- **验收**：因子 IC/分层/衰减可视化。

### 3.3 AI 分析中心（V2 多 Agent）

#### BP-V2-009 · 板块分析 Agent【P1】

- **输入**：板块代码/名称
- **输出**：板块热度、龙头股、补涨股、持续性研判、趋势分析、资金流向解读。

#### BP-V2-010 · 大盘分析 Agent【P1】

- **输入**：日期（默认当日）
- **输出**：指数趋势、市场情绪（涨停/炸板/封板率）、成交量、赚钱效应、情绪周期、仓位建议。

#### BP-V2-011 · 每日复盘 Agent【P1】

- **输入**：日期
- **输出**：今日热点板块、龙头股、炸板原因、资金流向、明日预判。

#### BP-V2-012 · 股票推荐 Agent【P1】

- **输入**：用户偏好（风格/风险）或多因子筛选
- **输出**：推荐股票列表 + 推荐理由 + 风险提示 + 止盈止损/仓位建议。

> 4 个 Agent 共享 V2 因子库 + V1.5 数据，输出结构化落 `sa_agent_report`。

### 3.4 AI 助手（V2 RAG）

#### BP-V2-006 · RAG 知识库【P0】

- **目标**：AI 助手从纯 LLM 升级为基于知识库的 RAG 问答。
- **功能点**：
  - 知识库导入：研报/公告/财报（文本分块 + 向量化）；
  - 向量检索：用户提问 → 检索相关文档片段 → 注入 LLM 上下文；
  - 引用标注：AI 回答附来源（"据 XX 研报..."）。
- **技术**：pgvector 向量存储 + LangChain RAG 链。
- **验收**：AI 能基于导入的研报回答问题并标注来源。

#### BP-V2-008 · 新闻情绪分析【P1】

- **目标**：实时资讯采集 + 情绪打分，辅助 AI 分析。
- **功能点**：
  - 采集财联社/东方财富实时资讯；
  - LLM 对每条资讯打情绪分（-1 极度悲观 ~ +1 极度乐观）+ 实体识别（个股/板块）；
  - 个股详情展示该股近期资讯 + 情绪分。
- **验收**：资讯可采集、情绪可打分、个股页可展示。

#### BP-V2-007 · Elasticsearch 全文搜索（下沉 V2.5）

> 本需求原计划 V2，但 ES 属架构升级范畴，**随架构升级下沉 V2.5**。
> V2 的文档检索由 RAG 向量检索覆盖（pgvector），个股搜索沿用 V1 的 SQL LIKE。

## 四、非功能性需求（V2 增量）

### 4.1 性能

| 接口 | 要求 |
|---|---|
| 因子计算（单因子一年） | < 500ms |
| 因子 IC 检验（全市场一年） | < 10s |
| 多因子打分（全市场） | < 3s |
| RAG 检索 | < 1s（Top 5 文档） |
| 组合回测（5 股 5 年） | < 15s |
| Agent 报告生成 | < 30s（含 LLM） |
| V1/V1.5 既有指标 | 不退化 |

### 4.2 数据合规（沿用）

- 数据源仅用公开授权渠道；
- RAG 知识库导入的研报/公告仅用于本地检索，不对外分发；
- 不对接交易接口（V3）；
- 所有 AI 输出标注风险声明。

### 4.3 可用性

- V2 目标可用性 95%；
- 因子/Agent 采集任务失败走 admin 日志 + 手动重跑（沿用 V1.5）；
- RAG 向量库写入失败不阻断问答（降级为纯 LLM）。

### 4.4 安全

- 组合/报告等用户数据按 user_id 隔离；
- RAG 文档导入需登录；
- 沿用 V1 JWT + 限流。

### 5.3 关键页面交互

#### 因子研究 `/factor`（BP-V2-001/013）

- 左侧：因子分类树（趋势/动量/.../情绪）+ 因子列表；
- 右侧：选中因子 → IC 分析（IC 柱状 + 累积 IC 曲线）+ 分层收益（5 档条形）+ 因子衰减曲线；
- 操作：因子叠加到 K 线、因子单独回测。

#### 组合管理 `/portfolio`（BP-V2-005）

- 组合列表卡片（名称/股票数/累计收益/夏普）；
- 创建组合：选股 + 设权重；
- 组合详情：净值曲线（组合 vs 基准）+ 回撤 + 持仓表 + 调仓记录；
- 回测：组合整体回测。

#### 回测增强 `/backtest`（BP-V2-003）

- 新增基准选择（沪深 300/上证 50/自定义）；
- 结果区新增：卡玛/IR/盈亏比指标卡 + 回撤曲线图 + 持仓变化图 + 净值对比图（策略 vs 基准）。

#### 多 Agent 报告 `/reports`（BP-V2-009~012）

- Tab：板块分析 / 大盘研判 / 每日复盘 / 个股推荐；
- 每个 Tab：报告列表（日期/标题/摘要）→ 点击查看正文（结构化 + 雷达图）；
- 复盘/推荐报告每日盘后自动生成。

#### AI 助手 RAG 增强 `/assistant`（BP-V2-006）

- 问答时若命中知识库，回答附"来源：XX 研报"引用；
- 知识库管理入口：上传/查看文档列表（admin 可管理）。

## 八、版本边界与不做的事（V2 Out-of-Scope）

为避免范围蔓延，明确 V2 **不做**（架构升级下沉 V2.5 / 交易下沉 V3）：

- ❌ Redis / Celery / ClickHouse / Elasticsearch / 微服务拆分 / K8s → **V2.5 架构升级**
- ❌ 模拟交易 / 实盘交易 → V3
- ❌ 多 Agent 协同（Agent 联动）→ V3
- ❌ AI Research Agent（自主投研）→ V3
- ❌ AI 自动优化策略（基于回测自迭代）→ V3
- ❌ 事件驱动策略 → V3

> V2.5 架构升级 PRD 将单独编写，待 V2 业务稳定后启动。
